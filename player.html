Custom Level Player 1.0.6

.adofai 파일과 곡 파일(ogg·mp3·wav)을 함께 선택하거나, 레벨 .zip 을 선택하세요. 파일은 기기 안에서만 처리되며, 한 번 선택한 맵은 아래 보관함에 자동 저장됩니다.

파일 선택
맵을 선택하면 시작 전에 타일·이벤트·장식 부하를 분석합니다.
렌더링 프리셋 · 핵심 기믹 보호 · 사전 부하 분석 · 재생 중 자동 성능 조절

자동 보호는 시작 전 부하를 추정하고, 재생 중 실제 프레임이 떨어질 때 후처리부터 줄입니다. 그래도 느리면 숫자·글자 핵심 연출을 남기고 일반 장식을 일시 생략합니다.

판정 방식 (원작 기준)

원작 방식: 판정은 타일의 각도 오차(±30°/±45°/±60°)를 BPM으로 시간 환산합니다. 느린 BPM에서는 허용 ms가 넓어지고, 빠른 BPM에서는 모드별 최소 ms(모바일 50/70/90 · PC 보통 25/30/65 · 느슨 25/30/91 · 엄격 25/30/40)에서 제한됩니다.

🔊 음악 볼륨 100%
효과음 볼륨 (히트음·카운트다운·보정 소리) 100%
입력 오프셋 0ms
고속 입력 오프셋 (200BPM 이상) 100BPM과 동일

사람은 느린 박자에서는 박보다 일찍, 빠른 박자에서는 박에 더 가깝게 누르는 경향이 있어 100BPM에서 맞춘 오프셋이 빠른 구간에서는 어긋나 느껴질 수 있습니다. 두 지점(100BPM / 200BPM)을 각각 보정하면 맵의 실제 BPM에 맞춰 그 사이 값이 자동으로 적용됩니다. 고속 보정을 하지 않으면 모든 속도에 100BPM 값이 적용됩니다.

🎵 음악 싱크는 맵 파일의 offset을 원작과 같은 방식으로 자동 적용합니다. 맵마다 따로 맞출 필요가 없고, 기기 지연은 위의 입력 오프셋(보정)만 쓰면 됩니다.

내 맵 보관함 (탭하면 바로 선택됩니다 · ✕로 삭제)
업데이트 로그 (눌러서 펼치기)

1.0.6: 버전 번호 갱신. 1.0.5: MoveTrack으로 위치가 이동한 타일은 일반 타일을 그린 뒤 다시 앞 레이어로 그려, 이동한 위치에서 다른 타일(마법진 경로 등)에 가려지지 않도록 수정. 특정 타일 번호나 맵에 종속되지 않으며, 위치 이동 중인 타일에만 적용. 1.0.4: 투명도를 낮추는 MoveTrack이 먼 타일을 즉시 강제 표시해 일반 경로와 마법진이 겹치던 문제 수정. 불투명도를 올리는 미리보기 이벤트는 유지. 1.0.3: 여러 타일을 한 번에 지정해 투명도를 올리는 MoveTrack(앞쪽 타일 미리보기·마법진 패턴)로 보이게 한 타일이 AnimateTrack beatsAhead 범위 때문에 숨겨지던 문제 수정. 1.0.2: Tile 기준 카메라가 MoveTrack으로 밀려난 타일을 따라가 화면 밖으로 벗어나던 문제 수정(N 맵 128번 근처에서 카메라가 너무 위로 가던 문제). 1.0.1: 업데이트 로그 기본 접힘, 화면 양옆 빈 곳을 드래그해도 메인 화면 스크롤. 타법 추천 다이얼 가로 배치 옵션 추가. 위젯/키뷰어 설정 안내창을 접을 수 있게 함(접으면 화면 전체에서 자유롭게 이동). 키뷰어를 켜 두면 HUD 위젯 설정에서 키뷰어 위치도 같이 옮기고 정렬 가능.

0.11.13: HUD 위젯 — 타일 요구의 t/s를 bpm과 같은 크기로, 위젯 크기 범위 확대(30~500%), 드래그 시 다른 위젯·화면 중앙에 딱 붙게 자동 정렬.

0.11.12: HUD 위젯 추가(타일 요구 bpm, 입력 t/kps, 요구 t/kps에 따른 타법 추천 다이얼). 위젯마다 위치·크기 설정.

0.11.11: 음악/효과음 볼륨 슬라이더 추가.

0.11.10: 키뷰어 설정에 '등록한 키만 입력' 추가, 입력 오프셋 설정을 접이식으로, 실패 후 화면 터치/아무 키로 다시 하기.

0.11.9: 키뷰어의 키를 터치하면 해당 키에 불이 들어오고 잔상이 올라감.

0.11.8: 키뷰어 추가(키보드로 원하는 키를 순서대로 등록, 누르는 동안 불이 켜지고 위로 잔상이 올라감. 크기·위치·잔상 높이/속도 설정).

0.11.7: 기기 화면 높이에 맞춰 UI(카운트다운·콤보·판정 바·판정 글씨·방향 안내·버튼) 크기를 조절해 어떤 기종이든 갤럭시 탭과 같은 비율로 보이게 함.

0.11.6: 맵 파일에 쉼표가 빠져 있어도(예: ] 뒤 "decorations") 불러오도록 파서를 보강.

0.11.5: 타일 폭을 조금 키움(원작 화면 비율에 가깝게).

0.11.4: 미드스핀 타일을 집 모양 오각형으로 변경.

0.11.3: 오프셋 모두 0 초기화 버튼 추가. 타일과 외곽선을 원작 두께에 가깝게 얇게 조정(빠른 삼각형 패턴이 보이도록).

0.11.2: 오프셋 보정이 한 박(예: 100BPM에서 600ms) 넘게 늦게 눌러도 정확히 측정되도록 수정. 보정 범위 ±1000ms.

0.11.1: 인터넷에 연결되어 있으면 시작할 때 새 버전을 확인하고, 있으면 업데이트할지 물어봅니다. 오프라인이면 마지막으로 설치된 버전으로 실행합니다.

0.11.0: 내장 맵을 모두 제거하고, 불러온 맵(.adofai+곡 / zip)을 기기 안에 저장하는 맵 보관함을 추가. 이름을 Custom Level Player로 변경.

0.10.9: 입력 오프셋을 속도(BPM)별로 보정. 100BPM과 200BPM에서 각각 보정하면 맵의 실제 BPM(피치 반영)에 맞춰 로그 보간해 적용합니다. 고속 보정을 하지 않으면 이전과 동일하게 동작합니다.

0.10.8: 플레이어 기준 카메라 이동 중 타일이 밀려나는 거리만큼 오프셋을 보정(Nyan Cat에서 카메라가 너무 앞서 가던 문제). 0.10.7: 카메라가 MoveTrack으로 옮겨진 타일/플레이어를 따라가도록 수정하고, LastPosition 카메라 이벤트가 추적 대상을 유지하도록 변경. 0.10.6: 같은 시각의 MoveTrack 이벤트가 서로 다른 항목(x/y/회전/크기/투명도)을 지정할 때 항목별로 적용하도록 수정(타일이 안 보이고 공만 움직이던 문제). 0.10.5: AnimateTrack의 음수 beatsBehind를 0으로 깎지 않고 지나온 타일을 유지하도록 수정. 0.10.4: 카메라 좌표 기준을 분리하고, 타일 숨김·표시 규칙이 이동 애니메이션에 의해 무시되지 않도록 보정했습니다. 숫자·텍스트·말풍선 핵심 연출 보호와 성능 조절은 유지됩니다. 핵심 연출은 자동 성능 보호 설정과 관계없이 가까운 구간부터 우선 로딩하고, 전체 카메라 장식을 시작 때 한꺼번에 큐에 넣지 않도록 했습니다. 기본 타일·카메라 처리 및 특수 이벤트의 원작 일치 여부는 계속 검증 중입니다.

켜고 끌 위젯을 고른 뒤, 화면의 위젯을 눌러 선택하고 드래그해서 옮기세요. 위젯마다 위치·크기가 따로이고, 다른 위젯이나 화면 중앙선에 가까이 가면 딱 붙게 정렬됩니다. 켜 둔 키뷰어도 여기서 위치만 옮길 수 있습니다. 위젯 설정창이 가리면 "접기"를 누르세요. (미리보기 숫자는 예시)
